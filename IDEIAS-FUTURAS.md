# Ideias para evolução do BC

A fonte oficial dos indicadores continua sendo a API do Banco Central. A proposta do PR #4 de substituir a consulta IBC-Br por outro fornecedor foi recusada; nenhuma mudança de fonte foi aplicada.

Como inspiração futura, estudar a organização e apresentação dos dados de https://open-economics-data.knbf982hkn.chatgpt.site/. Não utilizar esse serviço como fonte oficial nem implementar essa integração agora. Antes de qualquer adoção, verificar a origem dos dados, metodologia, atualização e disponibilidade; não foi confirmado se o serviço utiliza internamente a API do BC.
